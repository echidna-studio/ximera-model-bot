# Ximera Model Agent — бот приёма заявок

Telegram-бот [@ximeraagent_bot](https://t.me/ximeraagent_bot): модели заполняют анкету,
заявка с фото приходит администратору, он одобряет или отклоняет её одной кнопкой
и сразу переходит в личный чат с моделью.

## Как это работает

**Для модели:**
1. Открывает бота → `/start` → кнопка «📝 Оставить заявку».
2. Отвечает на 6 вопросов: имя, возраст, город, рост/вес, опыт, контакт.
3. Присылает 1–5 фото → «Готово».
4. Получает подтверждение и ждёт ответа.

**Для тебя (админ):**
- Заявка приходит сразу: фото + карточка с данными + кнопки
  **✅ Одобрить · ❌ Отклонить · 💬 Написать модели**.
- «Одобрить» → модель получает уведомление, а тебе появляется кнопка «Открыть чат» —
  дальше общаешься напрямую.
- `/admin` — панель: статистика и списки заявок (ожидают / одобренные / отклонённые / все),
  любую заявку можно открыть заново вместе с фото.

Возраст до 18 лет отсекается автоматически.

## Хостинг

Бот работает на GitHub Actions: воркфлоу `.github/workflows/bot.yml` запускает `bot.py`
циклами по ~5 ч 20 мин, а расписание (каждые 10 минут) ставит следующий запуск в очередь,
поэтому бот поднимается сам сразу после завершения предыдущего цикла.

Заявки хранятся в `data/db.json` и коммитятся обратно в репозиторий — история не теряется
между перезапусками.

### Секреты репозитория (Settings → Secrets and variables → Actions)

| Секрет | Значение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_ID` | твой Telegram ID (узнать: отправь боту `/id`) |
| `CLAIM_CODE` | (необязательно) код для команды `/claim <код>` — назначить себя админом |

### Если бот не отвечает
1. Вкладка **Actions** → workflow «Telegram bot 24/7» → **Run workflow** (запустить вручную).
2. Проверь, что секреты заданы и репозиторий публичный (у публичных репозиториев минуты Actions бесплатны).

## Локальный запуск

```bash
BOT_TOKEN=... ADMIN_ID=... python bot.py
```

## Данные

Бот собирает персональные данные (имя, возраст, город, рост/вес, контакты, фото).
Храни их аккуратно и не передавай третьим лицам без согласия соискателей.
